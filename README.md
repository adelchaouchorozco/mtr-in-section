# The MTR, in section

How Hong Kong built its railway in layers: an interactive explainer with a short animated film, a network map by year and level, a 3D model of the lines at their real depths, and sourced notes.

**Live site:** https://adelchaouchorozco.github.io/mtr-in-section/

A plain static site (HTML, CSS and JavaScript modules, no build step). All drawings are made in code. An independent explainer, not affiliated with or endorsed by MTR Corporation or KCRC.
